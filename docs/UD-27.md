## Casino (CASINO Grand) — Detail

### Besucherfluss
- **Stadtbewohner als Gäste:** Rita, Boris, Mira können Casino besuchen (`intent: CASINO`)
- **Externe Besucher:** `Visitor` mit `persona: STAMMGAST`, `HIGH_ROLLER`, etc.
- **Identität:** `CityResidentState.visitorId` = `Visitor.id` = `Guest.visitorId`
- **Ankunft:** `routeTo()` → `advanceTravel()` → `settleArrival()` mit `intent: CASINO`
- **Aufenthalt:** Spiele (SLOT, TABLE), Getränke, Toilette, Auszahlung

### Ökonomie
- **Einnahmen:**
  - Spieleinsätze: `playAction()` → `Ledger.transfer(GUEST, HAUSKONTO)`
  - Getränke: `serveDeskCmd` → `Ledger.transfer(GUEST, HAUSKONTO)`
  - Eintritt: `buyCmd` (Gewerberaum) → `Ledger.transfer`
- **Kosten:**
  - Personal: Bartender, Cashier, Guard, Cleaner, Porter → `payDailyWage()`
  - Upkeep: `payDailyUpkeep()` am Tageswechsel
  - Upgrades: Bar, WC, Reels, Mods → `Ledger.transfer(HAUSKONTO, EXTERNAL_WORK)`
- **Baukosten:** `buyCmd` (Möbel) → `Ledger.transfer(HAUSKONTO, EXTERNAL_WORK)`

### Besucher-State-Machine (Guest)
```
ENTER → EXCHANGE → CHOOSE → WAIT → PLAY → DRINK → TOILET → CASHOUT → LEAVE
```
- `tryGame()` nutzt `pickWeighted()` für Spielwahl (Issue #977)
- `guest-choice.ts` steuert Platzsuche und Aktivität
- `addictionScore` / `satisfaction` beeinflussen Verweildauer

### Erinnerungen & Disposition
- **Casino-Erinnerungen:** `Visitor.memories` aus `VISIT_ENDED` Facts (score, valence, tick)
- `applyMemories()` → `remember()` → `VisitorMemory` (factId, tick, score, valence)
- `memoryEffect()` → `returnBonus` + `moodBonus` für Disposition
- **Kiez/Casino Sync:** `syncResidentMemories()` spiegelt `Visitor.memories` → `CityResidentState.memories`

### Save/Load Casino-Zustand
| Feld | Serialisierung | Load-Verhalten |
|------|----------------|----------------|
| `cityLife` | `CityLifeState` (residents, memories, relationships) | `normalizeCityLife()` → `bindCityIdentities()` → `syncResidentMemories()` |
| `visitors` | `Visitor[]` mit `memories` | `ensureCityVisitor()` → `bindCityIdentities()` → `syncResidentMemories()` |
| `cityGrowth` | `CityGrowthState` (projects, population) | `normalizeCityGrowth()` |
| `scene` | `SceneState` (CITY/OWN/APARTMENT) | `loadWorld()` → `scene` restored |
| `narrative` | `NarrativeState` (facts, queue, flags) | `replaySave()` restores |

### Determinismus-Test (Save/Load Roundtrip)
1. Neuer Save → Casino-Betrieb → Stadtbesuch → Save
2. Load → Verifikation:
   - PRNG-State identisch
   - Ledger-Bilanz identisch
   - NPC-Positionen identisch
   - Memories (CityResident + Visitor) identisch
   - Beziehungen identisch
   - Disposition (returnBonus/moodBonus) identisch
