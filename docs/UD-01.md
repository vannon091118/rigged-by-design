# UD-01: Tageskreislauf — Ablauf und Verträge

**Zugehöriges Issue:** #973 (Lebenssimulations-Tag, CLOSED)
**Stand:** 2026-11-17 · Deterministischer End-to-End-Test liegt auf main (PR #1076, 8fc74834)

---

## Überblick

Der Tageskreislauf verbindet Wohnung → Stadt/Begegnung → Arbeit → Bedürfnisse/Konsum → eigener Betrieb → Tageswechsel → Folgetag → Save/Load-Wiederaufnahme. Alle Pfade sind deterministisch, keine zweite Simulationsmaschine.

---

## 1. Wohnung (Start)

- **Einstieg:** Spieler startet in Wohnung (`scene: APARTMENT`)
- **Aktionen:** `eatAtHome` (Hunger/Thirst senken), `drinkAtHome`, `stepPlayer` (Bewegung)
- **Save-Punkt:** Automatisch beim Verlassen der Wohnung über `scene.leaveApartmentAtDoor()`

---

## 2. Stadt / Begegnung (CITY Scene)

- **Eintritt:** `scene.arriveAtStreetDoor()` → `cityCmd` → `tickCityMovement()`
- **Bewohner:** Rita, Boris, Mira folgen Tagesroutine (HOME → KIEZ/MARKT → CASINO)
- **Bewegung:** `routeTo()` + `advanceTravel()` über `cityNav` (A* Pfadfindung)
- **Ankunft:** `settleArrival()` bucht Effekte (Geld, Skills, Bedürfnisse, soziale Kontakte)
- **Soziale Kontakte:** `selectSocialEncounter()` → `addMemory()` / `socialMemory()` → `NpcMemory` in `CityResidentState.memories`
- **Identität:** `bindCityIdentities()` verknüpft `CityResidentState.visitorId` mit `Visitor.id`
- **Sync:** `syncResidentMemories()` spiegelt `Visitor.memories` → `CityResidentState.memories`

---

## 3. Arbeit / Bedürfnisse / Konsum

- **Player-Jobs:** `acceptJobCmd`, `requestJobTaskCmd`, `buyBarCmd` — Lohn über `payDailyWage()` (automatisch via `staffTick` am Tageswechsel)
- **Bedürfnisse:** `eatAtHome` (Position ≤3 Manhattan-Distanz zur Kochnische), `drinkAtHome`
- **Konsum:** `serveDeskCmd`, `orderDrinksCmd`, `talkCmd`, `fightBrawlCmd`

---

## 4. Eigener Betrieb (Casino Floor)

- **Scene:** `OWN` — Bau, Einrichtung, Personal, Preise via `venue-commands.ts`
- **Gäste:** `Guest`-State-Machine (ENTER → EXCHANGE → CHOOSE → WAIT → PLAY → DRINK → TOILET → CASHOUT → LEAVE)
- **Spiele:** SLOT, BLACKJACK, POKER, ROULETTE, PLINKO, SHELL, DICE, VIDEO_POKER

---

## 5. Tageswechsel

- **Trigger:** `advanceToNextDay()` (manuell oder via `staffTick` bei `tickInDay === 0`)
- **Effekte:** `payDailyWage()` (Lohn), `cityGrowth` Check, `payDailyUpkeep()` (Unterhalt)
- **Save:** Automatisch via `saveWorld()` in `#emit()` nach jedem erfolgreichen Command

---

## 6. Folgetag

- **Wiederaufnahme:** `loadWorld()` → `replaySave()` → `ensureCityLife()` → `bindCityIdentities()` → `syncResidentMemories()`
- **Determinismus:** Gleicher PRNG-State, gleiche Ledger-Bilanz, gleiche NPC-Positionen/Erinnerungen

---

## 7. Save/Load-Roundtrip (Test)

- **Test:** `src/store/__tests__/life-sim-day.test.ts` (PR #1076)
- **Ablauf:** Neuer Save → ganzer Tag → Save → Load → Folgetag → Verifikation
- **Verifikation:** PRNG-State, Ledger-Bilanz, NPC-Positionen, Erinnerungen, Beziehungen identisch
