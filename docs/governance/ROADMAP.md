# Roadmap

<!-- rbd-doc: managed -->

## Kern
**Nordstern:** begehbare Lebenssimulation — Wohnung, Strasse, Stadt, Bewohner. Das Casino ist Start- und Testumgebung, nicht das Genre.
**Regel:** Status nur `erledigt`, `verifiziert`, `offen`, `blockiert`, `zurueckgestellt`; fertig nur mit Code- oder Testbeleg.

## Major-Ziele
| ID | Ziel | Exit |
| --- | --- | --- |
| M1 | Der erste Abend traegt | Ein Einstieg, ein Gast, bedienbar |
| M2 | Wohnung und Stadt als Raum | Wohnung, Strasse, Stadt ohne Teleport |
| M3 | Render und Living World ehrlich | Kein Fallback, echte Materialien |
| M4 | Wirtschaft und Events | Bar, Club, Arena, Wetten, E-Sport |
| M5 | Inhalt und Erzaehlung | 1.500 gewertete Textbausteine |
| M6 | Abnahme und Release | Performance, Geraete, Praesentation |
