## Kiez (KIEZ Pub) — Detail

### Besucherfluss
- **Stadtbewohner:** Rita, Boris, Mira mit `intent: PUB` oder `VISIT_FRIEND`
- **Externe Gäste:** `Visitor` mit `persona: STAMMGAST` etc.
- **Ankunft:** `routeTo()` → `advanceTravel()` → `settleArrival()`
- **Aufenthalt:** `intent: PUB` → Getränkekonsum, soziale Kontakte

### Ökonomie
- **Einnahmen:** Getränkeverkauf (`serveDeskCmd`) → `Ledger.transfer(GUEST, HAUSKONTO)`
- **Kosten:** Bartender-Lohn (`payDailyWage`), Getränkebestellung (`orderDrinksCmd`)
- **Personal:** Bartender (1 nötig für Service), Cleaner (optional für Flecken)

### Soziale Interaktion
- `selectSocialEncounter()` bei `intent: PUB` oder `VISIT_FRIEND`
- Partner in Reichweite (`INTERACTION_RADII.PUB`)
- `socialMemory()` → `NpcMemory` (kind: SOCIAL, sentiment ±)
- `addMemory()` → `CityResidentState.memories`
- `bindCityIdentities()` → `CityResidentState.visitorId` = `Visitor.id`
- `syncResidentMemories()` → `Visitor.memories` → `CityResidentState.memories`

### Save/Load
- `CityResidentState.memories` serialisiert in `cityLife`
- `Visitor.memories` serialisiert in `visitors`
- `syncResidentMemories()` bei Load

## Markt (MARKT) — Detail

### Besucherfluss
- **Stadtbewohner:** `intent: SHOP`
- **Externe Gäste:** Selten (nur Transit)
- **Ankunft:** `routeTo()` → `settleArrival()` mit `intent: SHOP`

### Ökonomie
- **Einnahmen:** Keine direkten (nur Transit-Ort)
- **Kosten:** Keine laufenden
- **Interaktion:** `orderDrinksCmd`, `orderPartsCmd` (Lieferungen an Spieler)
- **Lieferung:** `pickupCmd`, `deployCmd` für Kisten

### Save/Load
- Keine eigenen Memories (nur Transit)
- `cityLife` trägt nur Position/Intent
